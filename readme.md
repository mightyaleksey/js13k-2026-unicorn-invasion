# Unicorn Invasion

The repository contains the game made for the js13kGames competition in 2026.

Competition rules:

> Build a web game following the given theme within the next month and fit it into a 13KB zip package to win lots of cool prizes and respect from fellow developers!

> This time the theme is Unicorns and Rainbows!

## Design

Unicorn Invasion was inspired by Space Invaders game and features IDLE shooter game (kind of bullet hell).
